# 브릿지 커피 디지털 메뉴판

테이블의 QR코드를 찍으면 휴대폰으로 보게 되는 카페 메뉴판 웹페이지입니다.
파일은 `index.html` 하나뿐이고, 설치할 것 없이 브라우저에서 열면 바로 보입니다.

## 주요 기능

- **카테고리 버튼** — 전체 / 커피 / 논커피 / 디저트 (누르면 해당 메뉴만 보임)
- **사장님 pick! 배지** — 지정한 메뉴를 강조해서 보여줌
- **오늘 품절 표시** — 품절 메뉴는 흐리게, '오늘 품절' 도장이 뜸
- **영업시간, 주차·인스타 안내, 전화 걸기 버튼**
- 휴대폰 화면(가로 폭 390px) 기준, 색종이를 겹쳐 오린 듯한 디자인

## 보는 방법

`index.html` 파일을 더블클릭하면 브라우저에서 열립니다.

## 메뉴 고치는 방법

모든 메뉴 정보는 `index.html` 맨 위의 **'메뉴 정보 보관함'** 한곳에 모여 있고, 고치는 방법이 한국어 주석으로 자세히 적혀 있습니다. 자주 하는 작업만 요약하면 다음과 같습니다.

| 하고 싶은 일 | 고치는 방법 |
| --- | --- |
| 가격 바꾸기 | `가격: 4800` 의 숫자만 바꾸기 (쉼표, '원' 글자는 자동) |
| 메뉴 추가 | 같은 칸 안에서 메뉴 한 줄을 복사해 붙여넣고 내용 바꾸기 |
| 메뉴 삭제 | 그 메뉴의 한 줄을 통째로 지우기 |
| 오늘 품절로 만들기 | 그 줄의 `재고: "O"` 를 `재고: "X"` 로 바꾸기 (다시 팔 땐 `"O"`) |
| 사장님 pick! 붙이기 | 그 줄에 `시그니처: true,` 추가 (빼려면 지우기) |

## 파일 설명

| 파일 | 설명 |
| --- | --- |
| `index.html` | 메뉴판 본체 (HTML, CSS, JavaScript가 한 파일에 들어 있음) |
| `CLAUDE.md` | AI와 작업할 때 지키는 규칙 |
| `index-글래스백업.html` | 이전 디자인(반투명 유리 느낌) 보관용 |
| `자료.png` | 가게 정보 기획 시트 |

## 참고

- 고운 돋움 글꼴은 인터넷에서 불러옵니다. 인터넷이 안 되면 맑은 고딕 등으로 대신 보입니다.
- 전화번호(`062-000-0000`)는 기획 시트에 적힌 예시 번호입니다. 실제 번호로 바꿔 주세요.
  `index.html` 에서 `tel:` 뒤의 번호를 고치면 됩니다.
